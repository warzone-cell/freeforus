#### YTS / Yify Note

YTS / Yify has many fake copycat sites out there, make sure you're on one of the official domains before downloading anything. To be extra protected from fake sites, check out [FreeForUs SafeGuard](https://github.com/FreeForUs/FreeForUs-SafeGuard) and the [FreeForUs Filterlist](https://github.com/FreeForUs/FreeForUsFilterlist).
